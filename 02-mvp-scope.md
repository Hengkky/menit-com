# 2. Scope MVP

## Identitas produk

- Nama kerja: Menit.com
- Jenis: portal berita umum
- Target awal: website responsif dan aplikasi Android
- Konten: berita multi-kategori

## Fitur tahap awal

1. Beranda berita terbaru.
2. Kategori berita.
3. Halaman detail berita.
4. Pencarian berita.

## Kategori awal

- Nasional
- Daerah
- Politik
- Ekonomi
- Teknologi
- Olahraga
- Hiburan
- Lifestyle

Kategori dapat ditambah melalui CMS tanpa mengubah kode aplikasi.

## Di luar scope tahap awal

- Komentar publik.
- Live streaming.
- Video pendek.
- Personalisasi rekomendasi.
- Monetisasi iklan kompleks.
- Multi-bahasa.

## Kriteria selesai MVP publik

- Pengunjung dapat melihat berita terbaru.
- Pengunjung dapat memfilter berdasarkan kategori.
- Pengunjung dapat membuka detail berita.
- Pengunjung dapat mencari berita berdasarkan judul atau isi.
- Layout dapat digunakan pada layar Android.
